# Skills mentioned in the recap, sorted for you

Source: the Nate Herk 368-video recap (`053bd192-ALL-VIDEOS-RECAP.md`). He is selling courses, so treat it as a map, not a requirement. You do not need to learn all of it.

## Skills you already have (your edge)
Healthcare (CMA, phlebotomy, EKG, intake, documentation), nursing coursework, fluent Spanish, high GPA, stamina (40-46 hr/week while full-time), customer de-escalation (QuikTrip), Claude as your builder.

## Learn first (about 20 hours total, in this order)
1. **Discovery calls and selling outcomes**: listen, repeat back, poke with a question; quantify hours saved or dollars lost; sell the result, not the tool (#127, #129, #133).
2. **Pricing on value + a KPI baseline**: price at a fraction of value, agree one measurable KPI first (#156, #301, #317).
3. **Delivery and handover**: client owns accounts, scope and "done" in writing, separate maintenance retainer, signed webhooks, minimal personal data (#165).
4. **Describing workflows to Claude** (plan mode first, approve plan, test with dummy data): #171, #198, #293 (Claude Code for Non-Coders), #356.
5. **One automation end to end**: trigger -> AI step -> action -> alert, e.g. missed call -> text-back -> log -> notify (#143, #168, #213).
6. **Human-in-the-loop approvals**: the agent drafts, a person approves before anything sends (#47, #81). This is also how you use AI at work (you approve everything).
7. **Basic reliability**: error alerts, retries, test before going live (#74, #115).
8. **HIPAA basics**: no patient health data in tools without a business associate agreement (#130 warns about this).

## Learn later if the work needs it
- **Claude skills / CLAUDE.md / sub-agents / scheduled routines / MCP**: skill authoring (#190, #243 Skill Creator + Superpowers, #267), sub-agents (#270), scheduled tasks (#197, #204), MCP connectors (#61, #62, #71), context engineering (#112, #298).
- **RAG / document Q&A bots**: chunking, metadata, vector store (#3, #101, #131, #154). Good for clinic policy-manual bots; PHI caution.
- **Voice agents**: Vapi / ElevenLabs, receptionist and after-hours booking (#147, #159, #168, #244).
- **APIs and webhooks**: reading API docs, HTTP requests, credentials (#31, #82).
- **n8n**: nodes, expressions, sub-workflows (#155, #84, #70). Optional if Claude builds the workflows for you.
- **Creative production**: image/video generation (Nano Banana, Sora, Veo, Seedance), Hyperframes video editing, Claude Design, landing pages (#126, #146, #225, #233, #350).
- **Hosting**: self-host n8n/Claude agents on the Mac Mini, Docker, tunnels, VPS (#95, #97, #186, #228, #254).
- **Evals and model selection**: test a workflow on a labeled sample before selling it (#116, #125, #136).
- **Lead generation tools**: Clay, Apify, Firecrawl (#85, #182, #294). Check scraping and email consent rules first.

## Probably skip
Model-release reviews, trading bots, faceless shorts, Karpathy/second-brain/Obsidian setups, Codex vs Claude comparisons, AI safety news.

## Claude skills worth knowing exist
Skill Creator (turns a plain-English SOP into a reusable skill), Superpowers (plan + test-first workflow), Hyperframes (video from plain language), a "roast room" decision council (#363), a reverse-engineer skill (#364). Start with at most one.
