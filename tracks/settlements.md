# Track C: Class-action settlements

Only file for settlements you actually qualify for. Every claim form is a sworn statement that you are in the class, so "no proof required" does not mean "no eligibility required". Payouts are usually $5-$100, so this is a few hundred dollars at most, not income.

Always file through the official administrator site named in the settlement notice, never a third-party "claim service".
