## 343. 5 n8n Tips You NEED to Know
- **Link:** https://www.youtube.com/watch?v=Ctr89Q2Nei8 | **Length:** 17 min | **AI-relevant:** yes
- **Teaches:**
  - Continue on error: set a node to keep going when one item fails, so one bad URL does not stop a loop. Adding the error output lets you route failed items separately.
  - Parent and child agents: a parent agent calls a child workflow and waits for a "response" field. A quality-check model can send the query back for a retry.
  - Error workflows: build one with an Error Trigger, select it in the parent workflow's settings (the parent must be active), and send alerts by Telegram or email.
  - Fallback syntax: the double pipe catches any falsy value (0, empty string, null). The double question mark catches only null or undefined.
  - "From AI" expressions let a model fill tool parameters, such as calendar start time, attendees, and summary. Reference earlier nodes by name so inserted nodes do not break later steps.
- **Tools / prices / numbers:** n8n; Wikipedia tool; a chat model (not named); Google Calendar; Gmail; Telegram. The loop demo uses three URLs (McDonald's, Chipotle, and a fake one). No prices.
