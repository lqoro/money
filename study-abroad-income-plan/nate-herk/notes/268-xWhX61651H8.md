## 268. n8n Just Leveled Up RAG Agents (Reranking & Metadata)
- **Link:** https://www.youtube.com/watch?v=xWhX61651H8 | **Length:** 14 min | **AI-relevant:** yes
- **Teaches:**
  - RAG basics: chunk a document, embed the chunks into a vector database, embed the question with the same model, then pull back the nearest chunks.
  - Reranking: raise the retrieval limit (he sets 20 instead of the default 4), let a reranker score every chunk, then keep only the top 3 for the agent.
  - Metadata: tag each chunk when vectorizing (his example is a rule number) so the agent can filter on it. Chunks split across pieces lose their context without a tag.
  - Splitting a PDF into one item per rule with a code node, written in one shot by an AI model, then vectorizing each rule with its metadata.
  - Two-agent pattern: one agent chooses the metadata filter, and a second agent runs the vector search. He reports that letting one agent do both broke the node.
  - Read the agent logs (reranker input and output, with relevance scores) to debug retrieval.
- **Tools / prices / numbers:**
  - Tools: n8n AI Agent, Supabase vector store, Cohere Rerank v3.5, default data loader, code node, Excalidraw for diagrams.
  - Prices: none quoted. He says Cohere needs a free-to-create API key and does not state pricing.
  - Numbers: retrieval limit 20 (default 4), reranker keeps top 3, 43 rule items from a 22-page PDF, relevance scores for each chunk (his examples).
- **Skills shown:** RAG pipeline design, reranker setup, metadata schema design, metadata filtering, agent log debugging, prompt-driven code generation
