## 16. I Tested Sonnet 5.5 vs Opus 5.5. What You Need to Know.
- **Link:** https://www.youtube.com/watch?v=7eo-11K2e3c | **Length:** 26 min | **AI-relevant:** yes
- **Teaches:**
  - Head-to-head method: same prompt, same effort level (high), run both models in parallel, then judge output quality and cost per run.
  - Anthropic's own guidance on model choice: use Sonnet for well-scoped coding, bug fixes and polished documents or spreadsheets; use Opus for complex, long-horizon or judgment-heavy work.
  - Rule of thumb: if the task has a clear spec and a way to check the result, start with Sonnet. If the definition of done is subjective, use Opus as a thought partner.
  - Test by running each skill on both models and recording which model wins per skill, so you know which to use next time.
  - Tasks covered: landing page, motion reel, 90-day plan, pitch deck plus Excel model, local-AI explainer, news dashboard from scraped X posts, YouTube resource guide.
- **Tools / prices / numbers:**
  - Sonnet 5.5: $2 per million input tokens, $10 per million output tokens (his figures).
  - Opus 5.5: $4 per million input tokens, $20 per million output tokens (his figures).
  - Per-run costs in the tests: landing page about $13 (Opus) vs. under $5 (Sonnet); motion reel about $20.55 (Opus) vs. $14.37 (Sonnet).
  - Totals across 7 sessions: Opus about 46 min longer, about $16 more than Sonnet.
  - Scorecard: Opus won 3, Sonnet won 4 (his tally, mostly on cost when outputs were close).
