## 310. How I Automated Faceless Shorts with AI in n8n (free template)
- **Link:** https://www.youtube.com/watch?v=Gc03J27xmBc | **Length:** 37 min | **AI-relevant:** yes
- **Teaches:**
  - A Google Sheet of ideas drives the run. A row with status "to do" starts it, and a schedule trigger can run it several times a day.
  - An agent writes one family-friendly image prompt per animal. Prompts are cleaned of newlines and quotes before use.
  - Generate four images with a Flux model via Pi API, wait about 90 seconds, poll by task ID, then turn each image into a 5-second video with Runway.
  - Generate one 20-second sound effect with ElevenLabs, upload it to Drive and make it publicly readable, render the final video in Creatomate, upload to YouTube as unlisted, then update the sheet and send an email.
  - Nate says a weapon reference in a prompt broke the video generator, so he added a family-friendly rule.
- **Tools / prices / numbers:** Pi API (about 6 cents for four images); Runway (about 25 credits, roughly $1, per 5-second video); ElevenLabs ($5 starter plan); Creatomate (free tier, 36% of credits used); OpenAI GPT-4o; Google Drive; YouTube API. Nate estimates about $1 or a little more per run.
- **Skills shown:** API orchestration, polling, binary uploads, video template rendering, YouTube publishing, sheet-driven status tracking.
