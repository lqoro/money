## 188. How I'd Teach a 10 Year Old to Build Agentic Workflows (Claude Code)
- **Link:** https://www.youtube.com/watch?v=3GAxd90fEE4 | **Length:** 28 min | **AI-relevant:** yes
- **Teaches:**
  - Agentic workflow = state the goal in plain language; the agent plans steps, asks clarifying questions, and self-corrects. Contrast with node-by-node automation.
  - WAT framework: workflows (plain-language markdown SOPs), agent (Claude Code), tools (Python scripts), with a CLAUDE.md and folders for each.
  - Use plan mode for new jobs, and state inputs, outputs, and what "done" means (e.g., exactly 75 profiles, then stop).
  - Manage context: around 60% used, compact or reset (context rot).
  - Scheduled or webhook runs need deployed code; the agent builds and repairs tools but does not run on a schedule by itself.
- **Tools / prices / numbers:**
  - Claude Code (VS Code extension); Claude plan from about $17/month (Nate's statement).
  - Firecrawl MCP for scraping; free tier with 500 credits.
  - Demo: 622 remote jobs across 21 pages gave 209 rows; a sales-jobs pull needed a broader region (52 Europe-only, 372 with US added); a dentist lead pull gave 120 unique leads from four cities via Yellow Pages.
  - Nate's claim: agentic workflows are about 10x faster to build. Example: 90% accuracy per step falls to about 59% over five steps.
- **Skills shown:** Claude Code setup, MCP, prompt planning, workflow/tool structuring, scraping, lead list building, error recovery
- **Money angle:** Build agentic lead-gen and data-pull tools for clients (dentist contact lists, job listings). No client prices quoted.
- **Duet-relevant:** no
- **Promo:** Free school community (resource guide; "over 200,000 AI builders" claimed); plus community with weekly group calls and tech support (paid).
