## 188. How I'd Teach a 10 Year Old to Build Agentic Workflows (Claude Code)
- **Link:** https://www.youtube.com/watch?v=3GAxd90fEE4 | **Length:** 28 min | **AI-relevant:** yes
- **Teaches:**
  - Agentic workflow = state the goal in plain language; the agent plans steps, asks clarifying questions, and self-corrects. Contrast with node-by-node automation.
  - Set up Claude Code in VS Code, make a project folder, and keep API keys in a .env file rather than in chat.
  - WAT framework: workflows (plain-language markdown SOPs), agent (Claude Code), tools (Python scripts). Put it in a CLAUDE.md file and organize folders for workflows, tools, and temp files.
  - Use plan mode for new jobs, and state inputs, outputs, and what "done" means (e.g., exactly 75 profiles, then stop).
  - Manage context: around 60% used, compact or reset (context rot).
  - Scheduled or webhook runs need deployed code; the agent builds and repairs the tools but does not itself run on a schedule.
- **Tools / prices / numbers:**
  - Claude Code (VS Code extension); Claude plan from about $17/month (Nate's statement).
  - Firecrawl MCP for scraping; free tier with 500 credits.
  - Demo: 622 remote jobs across 21 pages produced 209 rows; a later sales-jobs pull needed a broader region (52 Europe-only jobs, 372 with US added); a dentist lead list gave 120 unique leads from four cities via Yellow Pages.
  - Nate's claim: agentic workflows are about 10x faster to build than step-by-step automation.
  - Per-step accuracy example: 90% per step drops to about 59% over five steps.
- **Skills shown:** Claude Code setup, MCP, prompt planning, workflow/tool structuring, scraping, lead list building, error recovery
- **Money angle:** Build agentic lead-gen and data-pull tools for clients (e.g., dentist contact lists for outreach, job listings). No prices quoted for clients. Start by writing a clear spec with a finish line.

- **Promo:** Free school community (resource guide, 200,000+ members claimed as "AI builders"); plus community with weekly group calls and tech support (paid).
