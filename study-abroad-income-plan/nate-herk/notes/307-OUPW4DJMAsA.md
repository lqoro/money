## 307. Ultimate No Code MCP Setup Guide (Self-Host, Installation, Common Issues)
- **Link:** https://www.youtube.com/watch?v=OUPW4DJMAsA | **Length:** 25 min | **AI-relevant:** yes
- **Teaches:**
  - Deploy self-hosted n8n with a one-click template on Elestio, adding a payment method and credits first; larger plans help MCP servers run.
  - Install the community node n8n-nodes-mcp from Settings, Community Nodes (self-hosted only).
  - Connect a server by copying the npx command and arguments from its GitHub README into a credential; Airbnb needs an extra "ignore robots" argument.
  - To use MCP as an agent tool, set the community-package tool-usage environment variable to true, then restart.
  - Use "list tools" first, then "execute tool" with model-filled parameters. Multi-step operations, such as Airtable record lookups, fail without the IDs.
