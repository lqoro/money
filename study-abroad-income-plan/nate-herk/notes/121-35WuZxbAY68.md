## 121. Overwhelmed By AI? Just Copy My Tech Stack
- **Link:** https://www.youtube.com/watch?v=35WuZxbAY68 | **Length:** 17 min | **AI-relevant:** yes
- **Teaches:**
  - His tiered AI stack: S tier (daily drivers) Claude Code, VS Code, and Glido; A tier (weekly) Codex, Claude chat, Hermes Agent, Perplexity, and Grok's X search; then specialists used for single tasks.
  - Coding agents are interchangeable harnesses; keep projects in plain directories so any agent can work in them.
  - Pick tools per step of a process, not one tool for the whole job; test whether your work would survive if your main tool went down.
  - Filter new tools by pain point: try one on real work for about a week, keep it only if it solves a problem, otherwise save the link and move on.
  - Measure productivity by progress toward a goal, not hours worked.
- **Tools / prices / numbers:**
  - Claude Code, VS Code, Glido (his speech-to-text startup, Windows support coming), Codex, Hermes Agent, Perplexity, Grok in X.
  - Specialists: Apify, GPT Image 2, Nano Banana 2, Key.ai, OpenRouter, HeyGen, ElevenLabs, Claude Design.
  - Graduated: ChatGPT, OpenClaw, Cursor, NotebookLM, Poppy AI, WhisperFlow.
  - Hostinger VPS for his agents. No prices given.
  - Rule he calls the "20% productivity dip": a change is worth it only if the dip ends above your old baseline.
