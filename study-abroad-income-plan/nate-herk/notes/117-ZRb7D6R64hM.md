## 117. Every Level of Claude Explained in 21 Minutes
- **Link:** https://www.youtube.com/watch?v=ZRb7D6R64hM | **Length:** 22 min | **AI-relevant:** yes
- **Teaches:**
  - A five-level ladder for using Claude: enthusiast, beginner, intermediate (Claude Cowork), level four (Claude Code power use), level five (architect, cloud automation).
  - Each level has a "cheat code" step: make a project with reference docs, set a folder structure Claude always reads first, then build repeatable workflows.
  - Level four habits: keep CLAUDE.md short, plan before editing, run parallel sessions in git worktrees, add custom slash commands, compact context early, and have Claude test its own work.
  - Level five hinges on trust: start with low-stakes cloud routines that only report to you, and watch them run for weeks.
- **Tools / prices / numbers:**
  - Cowork and Office add-ins need a paid plan; memory and file creation are free (his summary).
  - 50+ connectors, 100+ published skills, 16+ official Anthropic skills (his counts).
  - Claude Code hooks, routines (cloud, schedule/API/GitHub triggers), channels, remote control, agent SDK.
  - Claims: CLIs use 60-70% fewer tokens than the equivalent MCP server (cites Anthropic docs); prompt caching can cut long-session cost 60-90% (Nate's claim).
- **Skills shown:** Claude Desktop/Cowork setup, skill authoring, CLAUDE.md, plan mode, sub-agents, git worktrees, slash commands, hooks, cloud routines.
- **Money angle:** Non-coders can sell automation as a service at level three and up; level-four freelance or agency projects at $5k-$15k (Nate's figures, no pricing guidance beyond that).
- **Duet-relevant:** no (tangential only: level-five channels let you message Claude Code from Telegram or Discord, but it is a coding session, not a personal assistant).
