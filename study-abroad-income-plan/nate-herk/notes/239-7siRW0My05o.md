## 239. This Vapi + n8n Voice Agent Won $5,000 in Just 21 Days
- **Link:** https://www.youtube.com/watch?v=7siRW0My05o | **Length:** 19 min | **AI-relevant:** yes
- **Teaches:**
  - Winner Azim (interview) walks through a mental-health voice-companion web app built in Bolt, with 9 n8n workflows as the backend.
  - Onboarding form posts to an n8n webhook; AI agents write a user profile into a Google Sheet, and each call request spawns a personalized voice assistant.
  - Vapi places the outbound call; after the call an agent summarizes the transcript and updates the profile, so later calls build on past ones.
  - Guardrails: a safety check routes crisis messages to an emergency path, phone numbers are marked busy during calls, and a 30-second polling loop waits for call end.
  - Design rule from the host: keep flows linear with conditional checks, and use agents only where needed, not as open-ended tools.
- **Tools / prices / numbers:** Vapi (voice calls), n8n (9 workflows), Bolt (web app), Firebase (auth and user IDs), Google Sheets (profiles), Gmail (demo weekly email). $5,000 first prize for a 3-week hackathon in Nate's paid community (reported by Nate).
- **Skills shown:** Voice agent design, n8n webhooks and sub-agents, API-driven call control, Google Sheets as a profile store, error handling and polling, prompt writing per user.
- **Money angle:** Build voice agents for clients (Azim says he wants an agency). A passion project works as a demo to win clients. Sell templates or consultations. Note the caveat Azim raised: a mental-health product needs HIPAA and data protection, so it is not a quick launch. No price points stated.
- **Duet-relevant:** yes. A persistent companion that calls the user on a schedule (morning, evening, Sundays), remembers past calls and updates its profile.
