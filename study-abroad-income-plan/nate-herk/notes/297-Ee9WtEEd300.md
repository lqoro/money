## 297. Turn Any Website Into LLM Ready Data in Seconds with n8n & Firecrawl
- **Link:** https://www.youtube.com/watch?v=Ee9WtEEd300 | **Length:** 15 min | **AI-relevant:** yes
- **Teaches:**
  - Firecrawl turns websites into LLM-ready data. Its four endpoints are scrape, crawl, map and extract. Extract takes a URL plus a prompt and a schema and returns structured data.
  - Compare a raw HTTP request (messy HTML) with scrape (markdown) and extract (structured JSON). Use the Firecrawl playground to find the right prompt and schema, then copy the request.
  - Import the cURL for the extract endpoint into an n8n HTTP Request node. Store the API key once as a generic header credential (Authorization: Bearer) so it is reused.
  - Extract is asynchronous: it returns an ID. Poll a status endpoint with a Wait node, checking whether the data array is empty, and loop until it is filled.
  - A trailing wildcard on the URL makes Firecrawl crawl the whole domain. Without it, only one page is read (10 quotes instead of about 80).
