## 90. GLM 5.2 in Claude Code is Blowing My Mind
- **Link:** https://www.youtube.com/watch?v=2OD14-0cot4 | **Length:** 16 min | **AI-relevant:** yes
- **Teaches:**
  - GLM 5.2 (open-weight, hosted by z.ai) runs inside Claude Code. Setup is an env-var change: point the Anthropic base URL at z.ai and paste the z.ai key into settings.local.json.
  - Per-folder routing: a project folder with that settings file uses GLM, and a folder without it uses Opus on the Claude Max plan.
  - Pick the model per task. Typically heavy-reasoning work goes to Opus and research, drafting, and design go to GLM.
  - Research skill plus sub-agents with personas and a second review pass gives a usable HTML report. The strength is the orchestration, not the model.
  - Use a separate model to grade outputs (Codex wrote the tests and judged results).
- **Tools / prices / numbers:**
  - GLM 5.2: $1.40 input and $4.40 output per million tokens. Opus 4.8: $5 and $25 (Nate's figures, from the pricing pages he showed).
  - z.ai plans Nate cited: $16, $64, and $144 per month (yearly is cheaper). He used the $60 tier.
  - Website build: GLM 3 min 59 s vs Opus 14 min 59 s. Homework task: Opus about 5 min, GLM about 24 min.
  - Codex judged Opus better on one edge case (duplicate values like true vs 1).
  - Nate's claim: about 80% of knowledge work does not need the top model.
  - Ollama lists GLM 5.2 with a 1M context window; it is too large to run locally for most people.
- **Skills shown:** Claude Code settings and env config, per-project model routing, model comparison testing, sub-agent orchestration
- **Money angle:** cut your AI costs by routing each task to the cheapest model that passes; sell that setup to clients as a cost-saving service. No pricing given for services.
