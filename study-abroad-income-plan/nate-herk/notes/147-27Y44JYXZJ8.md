## 147. I Tested Claude's New Managed Agents... What You Need To Know
- **Link:** https://www.youtube.com/watch?v=27Y44JYXZJ8 | **Length:** 17 min | **AI-relevant:** yes
- **Teaches:**
  - Managed Agents sit in the Claude Console. You pick a template or describe an agent in chat, and it drafts the name, model, system prompt, tools and skills.
  - Setup has five steps: create the agent, configure a cloud environment (networking rules), connect tools through OAuth into a shared credential vault, start a session, then test-run it.
  - Editing the system prompt needs care. In his test, edits did not always reach the new agent version.
  - Agents only run when an API call triggers them. He could not get native cron or ClickUp-triggered wake-ups, so he needed glue code.
  - The Claude Code CLI can build a managed agent from a project that already holds business context.
- **Tools / prices / numbers:**
  - Live sessions cost about 8 cents per hour, plus token costs. Idle sessions and environments were not charged (his observation).
  - Starting needs an API key with about $5 of credit. No subscription is required.
  - Teased features need early-access applications: outcomes (self-evaluation loops), multi-agent orchestration, persistent memory.
  - Named tools: ClickUp, Notion, trigger.dev, n8n, OpenClaw.
- **Skills shown:** Claude Console setup, agent configuration, OAuth and credential vaults, prompt iteration, MCP connections, Claude Code CLI, scheduling workarounds
- **Money angle:** Aimed at people who live in Claude chat and want agents without infrastructure. Example use: a delegated research agent that picks up ClickUp tasks. No selling price is given. A start: $5 API credit, one template, one test run. Nate's view: experienced builders may find trigger.dev plus the Agent SDK cheaper.
- **Duet-relevant:** yes. He praises OpenClaw's heartbeats (cron check-ins every few minutes) and Telegram messaging as what makes an always-on assistant feel alive.
- **Promo:** his free school community (comparison PDF attached to the video's post); points to his own trigger.dev video.
