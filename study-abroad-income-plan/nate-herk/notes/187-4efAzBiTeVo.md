## 187. Turn Any Website Into LLM Ready Data INSTANTLY
- **Link:** https://www.youtube.com/watch?v=4efAzBiTeVo | **Length:** 11 min | **AI-relevant:** yes
- **Teaches:**
  - Firecrawl's MCP server lets Claude Code pick the right web tool (scrape, map, crawl, search) from a plain-language request.
  - Setup: create a .env file for the API key, connect the MCP server, reload the editor window.
  - Use a cheat-sheet markdown file for the tools, and a short CLAUDE.md that points to it, so the project knows its own tools.
  - Plan mode first for messy jobs. The agent may switch tools when an extract returns empty (it fell back to an agent-style tool).
  - Results: markdown, AI summary, links, HTML, full-page screenshot, and branding (logo, colors, typography) as structured data; output can be saved as CSV or spreadsheet.
  - Run two agents in parallel on separate sites.
- **Tools / prices / numbers:**
  - Firecrawl: free plan with about 500 credits, 2 concurrent requests; a hobby plan allows 5 concurrent requests. Nate used about 30 credits for the demo (about 6% of the free allowance).
  - Example job: about 1,700 listings found, Nate asked for 200; output was a 200-row sheet with title, company, salary, location, apply URL, and description.
  - Firecrawl's referral discount: 10% off a plan (affiliate link).
- **Skills shown:** MCP setup, Claude Code project setup, web scraping, site mapping, structured data extraction, prompt planning
- **Money angle:** Scraped lead lists, job boards, competitor or brand research, and data preparation for AI apps. Could sell structured data pulls or research to clients. No pricing beyond plan tiers.
