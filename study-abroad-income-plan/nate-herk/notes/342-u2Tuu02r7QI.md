## 342. Build this Multi AI Agent System for Research and Content Creation in n8n
- **Link:** https://www.youtube.com/watch?v=u2Tuu02r7QI | **Length:** 11 min | **AI-relevant:** yes
- **Teaches:**
  - A content sheet holds a campaign name, subject, and target audience. A new row triggers the workflow.
  - Research step: a Tavily news search on the subject returns recent articles (three in the demo), which are aggregated into one item.
  - Three specialised agents (LinkedIn, X, blog) each take the article content and audience, then write their post.
  - Switching from a tools agent to a conversational agent gave more natural prose, since these agents have no tools.
  - Results are written back to the same row, matched on campaign. Nate keeps a manual review step rather than auto-posting.
- **Tools / prices / numbers:** n8n; Google Sheets (row-added trigger polls about every minute); Tavily search API; a smaller LLM (the name is garbled in the captions). Grok was tried but had emoji problems. The demo sets a campaign for Christmas deals. No prices given.
- **Skills shown:** Sheets triggers and updates, HTTP API calls, research aggregation, multi-agent prompting, conversational agent setup.
- **Money angle:** Not stated. Inferred: small businesses might pay for a campaign-to-posts pipeline with a review step. Nate suggests adding a chat interface and visuals.
