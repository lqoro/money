## 181. I Can Actually Watch My AI Agents Work Now
- **Link:** https://www.youtube.com/watch?v=62Rfe1w9NBc | **Length:** 12 min | **AI-relevant:** yes
- **Teaches:**
  - Three ways to run several agents: parallel agents (separate terminals, each its own task), sub-agents (a parent delegates to children with their own context and optionally a different model), and agent teams (share a task list and can message each other; not yet shown in his tool).
  - Pixel Agents, a VS Code extension, turns each Claude Code agent into an animated character in a virtual office, driven by Claude Code's activity log. It shows which agents are working, idle or waiting for approval.
  - Setup: install from the VS Code extensions panel, open a folder whose name has no spaces or periods, open the terminal, and click "+ agent" to spawn each one.
  - Vet extensions before installing: check the publisher, look for outbound network calls, file access, shell execution, credential handling and remote script loading. Nate did this and found nothing concerning.
- **Tools / prices / numbers:**
