## 25. How to Build Codex Skills Better than 99% of People
- **Link:** https://www.youtube.com/watch?v=9KOtMsZ9I28 | **Length:** 27 min | **AI-relevant:** yes
- **Teaches:**
  - Reverse-engineer a skill from an output you already like: have the agent walk back through the data sources, calculations and formatting.
  - One skill, one job, one trigger. Split a broad job into small skills. The YAML front matter sets the name and when to invoke it.
  - Set the freedom level. Rule-based steps can be scripted step by step; judgment-heavy steps (creative work, screenshots) need a definition of "good" instead.
  - Verification loops: objective checks (counts, source totals) plus subjective checks (tone, layout), often by a second agent acting as judge. Ask for a QA report.
  - Walk the model down (Astra, Sol, Terra, Luna) and the effort level until quality drops. Then run the "bike method": give good and bad feedback each run and have the skill update itself.
- **Tools / prices / numbers:**
  - Codex with GPT-6 Astra, Sol, Terra and Luna. Runtimes on one X-article skill: Luna 28 min 33 s, Terra about 26 min, Sol 38 min.
  - Nate normally runs Astra on low effort in fast mode.
- **Skills shown:** skill authoring, prompt design, QA and eval loops, model selection, browser screenshots, X article publishing.
