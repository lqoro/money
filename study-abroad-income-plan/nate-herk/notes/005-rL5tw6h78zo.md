## 5. I Tested the Viral Reverse Engineer Anything Skill. What You Need to Know.
- **Link:** https://www.youtube.com/watch?v=rL5tw6h78zo | **Length:** 15 min | **AI-relevant:** yes
- **Teaches:**
  - Reverse engineering an app or workflow means pointing an agent at a working example, having it study the behavior, then rebuilding the functionality rather than the exact UI or code.
  - Give the agent a concrete target (a "PRD by example"), such as five strong examples of a report, and it produces more specific results than a generic goal.
  - The REA framework runs five steps: pick a specific feature, route by how the app is built, get a summary first and save it locally, tag findings as seen, inferred, or unknown, then rebuild and test in iterations.
  - Keep the unknowns labeled so guesses are not built on as facts.
  - Only inspect what is already accessible to you (local files, public apps, or your own API access). Do not copy exact code or assets.
- **Tools / prices / numbers:** Reverse-engineer-anything (REA) GitHub repo, about 192k stars at recording (Nate's claim, tracked live). Claude Code, Opus, Sonnet. Langfuse is mentioned as an inspiration for his eval tool. No prices stated.
