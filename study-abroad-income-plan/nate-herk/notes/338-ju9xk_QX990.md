## 338. Understanding APIs in n8n (as a beginner)
- **Link:** https://www.youtube.com/watch?v=ju9xk_QX990 | **Length:** 17 min | **AI-relevant:** yes
- **Teaches:**
  - An API is a set of rules that lets software talk to other software. Nate uses a restaurant waiter as the analogy.
  - REST methods: GET reads, POST creates or sends, PUT replaces, PATCH partially updates, DELETE removes. GET and POST cover most use.
  - Read a provider's docs to find the endpoint, required parameters (for example latitude, longitude, API key), and optional ones (units).
  - n8n has three routes: an HTTP Request node, a built-in integration node (OpenWeatherMap), or a POST request to a search API.
  - An LLM node can summarise raw API output into readable text.
- **Tools / prices / numbers:** n8n HTTP Request node; OpenWeatherMap API; JSONPlaceholder (free test API: 100 posts, 500 comments); Tavily search API (three news articles returned in the demo). An LLM is used to summarise but the model is not named. No prices.
- **Skills shown:** HTTP requests, query parameters, API key auth, reading API docs, JSON output handling.
