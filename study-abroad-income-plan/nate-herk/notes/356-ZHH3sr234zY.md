## 356. n8n Masterclass: Build AI Agents & Automate Workflows (Beginner to Pro)
- **Link:** https://www.youtube.com/watch?v=ZHH3sr234zY | **Length:** 91 min | **AI-relevant:** yes
- **Teaches:**
  - n8n basics: workflows (recipes), nodes (steps), and executions (each run); triggers, action, data transformation, and logic nodes (If, Switch, Wait).
  - Self-hosted vs. cloud n8n: self-hosting gives data control and no subscription but needs server upkeep; cloud is managed and subscription-based.
  - Build a small workflow: a Google Sheets row trigger, an OpenAI summary, and a Gmail send, then test with real rows and fix date formatting from the execution log.
  - RAG explained: retrieve relevant chunks from a vector database, then have the model answer from them. Chunking choices (character, recursive, token splitters) and binary vs. JSON loading.
  - Build a Nike earnings PDF chat agent in Pinecone with a namespace, then add a tools prompt, memory, and a Wikipedia tool.
  - Workflows as agent tools: a personal assistant on Telegram that calls sub-workflows (email, calendar, database), and a Gmail label-and-route agent.
  - APIs and HTTP requests: endpoints, calls, and methods (GET for reading, POST for sending); use built-in nodes first.
  - Error workflows: an error trigger that sends a Telegram or email alert with the failed run link.
- **Tools / prices / numbers:**
  - n8n (cloud subscription, usage-based tiers; no prices stated), OpenAI GPT-4o and GPT-4o mini, Pinecone (described as cheap, free to start), Google Cloud OAuth, Telegram, Gmail, Google Calendar, OpenWeatherMap example
  - Nike PDF loaded as 29 vectors (his figure)
  - n8n offers over 300 built-in integrations (his claim)
- **Skills shown:** workflow building, credential setup, JSON handling, RAG pipeline, agent prompting, tool design, HTTP requests, error handling
- **Money angle:** none stated. He frames n8n skills as a way to automate work and says savings or income depend on the user; no product or price points given.
- **Duet-relevant:** yes - he demos an always-on Telegram personal assistant that reads email and calendar and updates a database on request.
