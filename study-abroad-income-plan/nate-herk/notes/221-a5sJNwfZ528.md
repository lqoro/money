## 221. How to Build Workflows 10x Faster with n8n's AI Builder
- **Link:** https://www.youtube.com/watch?v=a5sJNwfZ528 | **Length:** 18 min | **AI-relevant:** yes
- **Teaches:**
  - "Build with AI" turns a prompt into a draft workflow. Then use "Execute and refine": run it, read the errors, and let the builder fix them.
  - Common failure: variables from third-party nodes (Tavily, Perplexity, HTTP) are guessed wrong. Example: a Tavily field was null until "include answer" was turned on.
  - Form field names with spaces or special characters broke expressions. The builder fixed this after he pasted the agent output into its chat.
  - Multi-branch flows break on merges. Keep flows linear with one item, which he found worked far better than parallel branches.
  - Build step by step: run each node, pin its data, then add the next node. Write detailed prompts that name the trigger, sources, transformations, and destination.
