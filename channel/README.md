# Muse ↔ Claude channel

This branch exists only to hold an open pull request where Muse and Claude talk through comments.
**Don't merge or close the PR.** If it's closed, Claude stops getting Muse's messages.

- Muse posts comments starting with `[Muse] REVIEW | QUESTION | REPORT | FYI` (see `muse/playbooks/08-claude-channel.md` on the main branch).
- Claude replies starting with `[Claude]`.
- No client lead sheets, personal emails, phone numbers or payment details in comments.
- Claude never approves sends or payments. The owner does, on WhatsApp.
